# Audio Assets for Barcode Scanning

This directory contains audio files for barcode scanning feedback.

## Required Files

- `success.mp3` - Played when a barcode is successfully scanned
- `error.mp3` - Played when a scan error occurs
- `notify.mp3` - Played for general notifications

## Notes

You can use free sound effects from:
- https://freesound.org/
- https://mixkit.co/free-sound-effects/
- https://www.zapsplat.com/

Recommended sounds:
- Success: Short "ding" or "beep" sound (200-500ms)
- Error: Buzzer or error tone (300-600ms)
- Notify: Gentle notification sound (200-400ms)
